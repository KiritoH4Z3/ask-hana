## Accepted risks

1. **Claude path unverified against the live API** (row 1). Mock tests only. Run one real question with a key before claiming it works.
2. **No step-1 reference screenshots** (row 26). Two references were read from the local design library and one non-web reference was used; none was captured.
3. **ChromaDB advisories without a fixed release** (row 9). Not reachable here. Re-run `pip-audit` before each release.
4. **Retrieval threshold fitted in-sample**, with a 0.02 margin on the weakest answerable question; the first chip clears the line by 0.005. `tests/test_chips.py` goes red if a corpus edit breaks it.
